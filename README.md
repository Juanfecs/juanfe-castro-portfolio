# Juanfe Castro — Portafolio audiovisual

Proyecto web autónomo en React + TypeScript + Vite, preparado para publicarse gratis en Vercel.

## Publicar

1. Extrae el ZIP.
2. Crea un repositorio en GitHub y sube todos los archivos y carpetas que están dentro de esta carpeta (incluyendo `package.json`, `index.html`, `vite.config.ts`, `tsconfig.json` y `src/`).
3. Entra en https://vercel.com, regístrate con GitHub y pulsa **Add New → Project**.
4. Importa el repositorio. Vercel normalmente detecta Vite automáticamente. Si pide configuración: Build Command `npm run build`, Output Directory `dist`.
5. Pulsa **Deploy**. Al terminar, Vercel mostrará la URL pública `*.vercel.app`.

## Editar el contenido

Edita `src/data/site.ts` para cambiar textos, correo, Instagram, proyectos e imágenes. Los proyectos que aparecen inicialmente son ejemplos: sustitúyelos por trabajos reales antes de presentar el sitio como portafolio definitivo.

## Desarrollo local (opcional)

Requiere Node.js instalado. En esta carpeta ejecuta `npm install` y luego `npm run dev`.
